Code is data

A program is a value your system can read, write, and keep.

ALGAL programs are typed data with a content-derived identity. A Lisp-shaped surface lowers to the same manifest as readable source, so a person, a macro, or a model can author a procedure, and the host checks it the same way.

quote.lisp
01 / Write it as an S-expression
(program quote ((order json)) json
  (with-total subtotal
    (* (get order quantity) (get order unit_price))
    (record subtotal subtotal
            shipping (if (>= subtotal 50) 0 5)
            total (+ subtotal (if (>= subtotal 50) 0 5)))))

The macro expansion is printed and hashed.
Generated code stays inspectable, and the manifest digest matches the readable source exactly.

02 / Compose it
(program gross ((order json)) json
  (let gross (* (get order price) (get order quantity))
    (let tax (* gross 0.08)
      (record gross gross tax tax total (+ gross tax)))))

Immutable bindings, bounded fuel, no hidden effects.
Syntax never grants authority. Waits, tools, and limits are declared in the manifest.

Once a procedure works, it keeps its digest, its evidence, and its place in every larger program that calls it.

Capabilities

{{HEADING_HOME_PROCESS}}

Use ALGAL for approval queues, repeatable model decisions, and tasks whose history you need to inspect.

waits

Wait for an approval or message, then resume in a new process. Confirmed work is reused; a write with an unknown outcome stays blocked.

remembers

Keep program memory between runs in the local store, with semantic search for recalling related material.

decides

Give each model decision its own context, expected answer format, and budget. The rest of the program follows deterministic logic.

reproduces

Have a program propose another program. ALGAL checks it before running it within the parent's limits.

evolves

Score candidate programs on your test cases and choose which to keep. Their scores and history are saved.

replays

Inspect a saved run and replay its logic without calling a model or connecting to the original services.

The habitat

{{HEADING_HOME_HOST}}

Run a program with the native CLI or the TypeScript runtime. Both can resume the same saved run on a shared local store.

A program cannot give itself tool access or raise its own limits. Your application supplies those permissions.
