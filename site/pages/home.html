How it works

{{HEADING_HOME_HOST}}

The program is data. Your host runs it with the tools and budgets it grants, records every effect, and can replay the record.

  1. CheckThe host reads the program and its budgets before anything runs.
  2. RunModel calls and tools run through the permissions the host attached.
  3. RecordEvery step lands in a store either runtime can continue from.
  4. ReplayThe record verifies offline, with no model in the loop.

Compared

If you run Temporal, Restate,
Inngest, or LangGraph.

ALGAL shares their vocabulary. The difference is that the workflow is data a host can inspect, hash, and run, not code in your process.

If you useALGAL differs in
Temporal or RestateThe workflow is a hashed program, not host code; the run verifies offline.
InngestA step is a typed model decision or a pure expression with a recorded budget.
LangGraphThe graph cannot call your process; your host grants every tool and model.
A plain agent loopThe run pauses for people, exits, and resumes on another machine.
