    Task and workflow history
    Each workspace holds up to 32 tasks and 128 history steps. At the task limit, edits remain available. A full history blocks further task and workflow changes.
      
      
      Offline use and backups
      Preparing the application for offline use…
      Tasks, saved drafts, and workflow previews are stored in IndexedDB for this site. An export includes tasks and applied history; it excludes drafts and unapplied proposals. Imports accept files up to 8 MiB and create a separate workspace. Export before clearing browser storage, which browsers can also remove. Recovery records include all stored data and may include drafts.
      Offline saving covers this application and its assets. Each workspace has its own URL; bookmark it or use Back to return. Other site pages need a connection.
