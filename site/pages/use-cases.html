Coding repair · Bun host

A coding attempt ends.
The checks decide what follows.

Pin a source revision and the test commands that must pass. ALGAL keeps the agent's proposed patch, runs those tests against that exact patch, and produces a review packet. If it cannot tell whether a coding job started, it leaves the job unresolved instead of quietly launching another.

You keep: the patch digest, the source revision it applies to, test results, and a record of which process owns any job whose outcome is still unknown.

Execution audit · Either runtime

Share the history.
Verify it elsewhere.

Export a process's execution history as one size-limited file. Verification needs no model or credentials and still works after the original store is moved away. Verification fails if a hashed record was altered or a dependency is missing.

Check the saved prompts, outputs, and capability strings before you share the file; the export does not redact them.

You keep: one portable file and a verified copy of the latest process state.

# Inspect the installed build identity
algal doctor

# Leave a VM process waiting for your decision
algal demo start ./my-review
algal demo inspect ./my-review

# Open my-review/report.html for the exact decision command

# Kill owned VM children and check their recovery
algal demo prove ./crash-laboratory

crash-laboratory/proof.json records an approval that publishes once, a denial that publishes nothing, completed writes reused after a crash during a read, and a write with an unknown outcome that is not sent again. The decisions are fixtures; everything else, including the processes, journals, and verification, runs in the VM.
