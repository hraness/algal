A writing assistant and an agent router need different kinds of control. Each can use a small typed program to make part of its work explicit: what it receives, what it may do and how its result is checked.

These product guides show those choices in working integrations. Follow the example closest to your own task, then inspect the linked source to see where the host application hands work to ALGAL.
