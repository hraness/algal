# Expression corpus pilot

`ALGAL_CORPUS_NATIVE_BIN=/absolute/verification_boundary bun scripts/verify.ts --suite corpus` runs the finite native profile and immediately admits its exact retained archive against current source and artifact bytes. The native executable must support `eval <input-file>`; build it through the repository's existing native qualification workflow. No build is performed by this suite. The first matrix is fixed at 115 cases (96 grammar and 19 raw), 230 supervised commands and 326 observations across committed WASM, its Bun public wrapper and native execution. Zero or omitted cases/targets cannot pass. The suite is infrastructure-only and leaves Phase 08, differential, fuzz-smoke and evidence-mutation incomplete.

The adapter selects its archive, definition and artifact authority before execution; archive metadata never supplies its own admission authority. Historical reader admission is separately named and does not prove current applicability or execution provenance. Synthetic reader tests exercise metadata and semantic rejection without target execution. They are not live qualification receipts. Whole source inventory includes the pilot, reader, adapter, tests and existing governed repository closure. Host runtime, filesystem cooperation and the finite oracle's admitted domain remain explicit premises.

Per-case execution uses the existing supervised runner, 10-second deadline, 1 MiB output cap, 16 MiB aggregate capture, 8 MiB metadata records, 32 MiB archive with 64 KiB terminal reserve, and 2048-file budget. Exact archive inventories reject extra files, directories and symlinks. Bun eagerly allocates readdir names before inventory admission; this is not a hostile-directory allocation or whole-process RSS proof. Failure retention preserves primary semantic/infrastructure errors. See SCOPE.md for oracle and shrink limits.

Standalone local/full/replay exploration remains available through `bun verify/corpus/run.ts <local|native|full> [native|-] [rebuilt|-] [case.json]`. These standalone profiles do not count as the registered first matrix and require separate current-source readmission. `full` adds an explicitly supplied rebuilt WASM artifact; build provenance remains the artifact suite's separate obligation. The registered corpus suite consumes ALGAL_CORPUS_NATIVE_BIN explicitly; include this variable in the integration owner's final-gate environment.
